# 04 · API reference

Base path: `/api`. Interactive docs are generated by FastAPI at **`/docs`** (Swagger UI) and
**`/redoc`** when the server is running.

## Conventions

- All request and response bodies are JSON, except file upload (`multipart/form-data`).
- A **session** scopes all data. Create one, then pass its id in every path.
- Errors always have the same shape:

```json
{ "error": "Human-readable message, safe to show the user", "detail": "optional technical detail" }
```

| Status | When |
|---|---|
| `400` | Too many files for the session |
| `404` | Unknown session or table |
| `413` | File exceeds size cap (reported per-file inside a 200 upload response) |
| `415` | Unsupported file type (reported per-file inside a 200 upload response) |
| `422` | File readable but not convertible to a table |

---

## `GET /api/health`

Liveness probe. → `200 {"status": "ok"}`

---

## `POST /api/sessions`

Create a session.

**Response `200`**
```json
{ "session_id": "19ca879444d2", "created_at": "2026-09-17T16:55:01.123Z" }
```

---

## `DELETE /api/sessions/{session_id}`

Delete a session, its uploaded files, and its database. Idempotent. → `204`

---

## `POST /api/sessions/{session_id}/files`

Upload one or more files. Repeat the `files` field for each file.

```bash
curl -X POST http://localhost:8000/api/sessions/$SID/files \
  -F "files=@employees.csv" \
  -F "files=@salaries.xlsx"
```

Returns `200` even if some files fail — check each file's `status`. The `schema` field is the
full refreshed catalogue (same shape as `GET /schema`).

**Response `200`**
```json
{
  "session_id": "19ca879444d2",
  "files": [
    { "filename": "employees.csv", "status": "ok",     "tables": ["employees"], "error": null },
    { "filename": "salaries.xlsx", "status": "ok",     "tables": ["salaries_2023", "salaries_2024"], "error": null },
    { "filename": "notes.pdf",     "status": "failed", "tables": [], "error": "'notes.pdf' is not a supported file type. ..." }
  ],
  "schema": { "...": "see GET /schema" }
}
```

Limits (configurable, see `.env.example`): 50 MB per file, 10 tables per session.

## `GET /api/sessions/{session_id}/schema`

The profiled catalogue. Served from cache; pass `?refresh=true` to force re-profiling.

**Response `200`**
```json
{
  "session_id": "19ca879444d2",
  "created_at": "2026-09-17T16:55:01.123Z",
  "tables": [
    {
      "name": "employees",
      "source_file": "employees.csv",
      "sheet_name": null,
      "row_count": 120,
      "columns": [
        {
          "name": "performance_rating",
          "original_name": "Performance Rating",
          "dtype": "DOUBLE",
          "semantic_type": "numeric",
          "null_count": 12,
          "null_fraction": 0.1,
          "distinct_count": 4,
          "sample_values": [3.0, 4.0, 2.0, 5.0],
          "min_value": 2.0,
          "max_value": 5.0,
          "categories": [2.0, 3.0, 4.0, 5.0]
        }
      ]
    }
  ],
  "join_hints": [
    {
      "left_table": "departments", "left_column": "id",
      "right_table": "employees",  "right_column": "department_id",
      "overlap": 1.0, "confidence": "high"
    }
  ]
}
```

`semantic_type` ∈ `identifier | numeric | temporal | categorical | boolean | text`.
See [03 · Data pipeline](03-data-pipeline.md#semantic-types).

## `GET /api/sessions/{session_id}/tables/{table}/preview`

First rows of a table. `limit` defaults to 20, clamped to 1–200.

**Response `200`**
```json
{
  "table": "departments",
  "columns": ["id", "department_name", "location", "function"],
  "rows": [ { "id": 1, "department_name": "Engineering", "location": "Bangalore", "function": "Technology" } ]
}
```
